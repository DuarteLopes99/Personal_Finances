Data

Files

Add

Bank exports (xlsx, xls or csv), several at once. Transactions already in the store, or repeated across the files, are skipped.

Save and export

With the local server running, reviews, rules and the store are saved to data/ as you go, and the server refuses any save that would remove a transaction already in data/transactions.csv. These are copies for when it isn't running.

Danger zone

Each of these throws away what is loaded. To add a month, use "Add monthly file(s)" above — it never removes anything.

Replace all history

Swaps every transaction for the ones in a store file, after you type a confirmation. The current data/transactions.csv is backed up in data/ first. A bank export picked here is added like a monthly file instead, and replaces nothing.

Clear this tab

Empties this tab's working copy. Nothing on disk changes, and saved review decisions come back as the rows do.

Data health

    Where your data lives

    Files in data/, whether they are encrypted, and whether git may hold them
    FileHoldsIn git?
    data/transactions.csvThe store, in plain text. What this page loads and saves. No — gitignored, and the pre-commit hook refuses it.
    data/transactions.csv.encThe store, encrypted (AES-256-GCM, your passphrase). Yes — the only copy meant for git.
    data/review_decisions.jsonYour reviews and notes, so they survive a rebuild. No — gitignored and blocked by the hook.
    data/category_overrides.jsonRules you taught: merchant keywords and peer rules. Yes — but a peer rule holds a person's name, so check before committing.
    data/transactions.backup-*.csvCopies made by reset_store.py and recategorize.py. No — plain text, gitignored.
    Bank exports (.xlsx, .xls)Raw statements. Keep them outside the repo. No — ignored everywhere and blocked by the hook.

    Encrypt before committing with python3 scripts/encrypt_store.py; decrypt with scripts/decrypt_store.py, or load the .enc file above. The local server only ever writes the three files the page saves, and only on 127.0.0.1.
